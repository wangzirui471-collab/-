# 泰合技术点云查看网站

`dist/` 是公开网站的文件目录。打开网站会自动显示 `cloud_20260922_053021_559.pcd`；访客也可以在浏览器中选择自己的 PCD 文件临时查看，所选文件不会因此上传到网站。查看器默认启用飞点滤波，可选择保守、标准或强三档，也可关闭滤波对比原始点云。滤波只影响浏览器中的显示，不会修改或重新保存原始 PCD。

Three.js 及其控制器和 PCD 解析器已经放在 `dist/vendor/`，页面不依赖第三方脚本域名。

页面下方的模型信息会随当前 PCD 更新；“下载当前 PCD”下载正在查看的文件。“分享”只分享公开网站地址，“嵌入”生成公开样例的 iframe 代码。访客从本机选取的 PCD 不会上传，也不会出现在分享链接里。`?embed=1` 是精简嵌入模式。点云不含三角面，授权信息未经提供，因此页面标记为“未注明”。

迁移到 GitHub Pages 时，将 `dist/` 内的全部文件放到仓库根目录（不要多套一层 `dist/`），并在仓库 Settings → Pages 选择从默认分支根目录发布。GitHub Pages 只能展示静态文件，不能保存访客上传的 PCD；如需让他人看到新点云，必须将文件发布到仓库并更新默认文件路径，或后续接入专门的文件存储服务。

后续更新默认点云时，替换 `dist/` 中的 PCD，并同步修改 `dist/index.html` 的 `data-point-cloud` 和 `dist/app.js` 的 `DEFAULT_POINT_CLOUD` 文件名，再发布新版。
